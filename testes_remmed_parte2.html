Módulo 9 — Opção 6: Emagrecimento / IMC
IMC ≥30 agenda direto · IMC 27–29.9 pergunta comorbidade · IMC <27 amarelo · GLP-1
5 testes
✓
M9.1 — IMC ≥30: agenda direto
Quero emagrecer. Peso 95kg e tenho 1,70m
Esperado: IMC = 95 / (1,70²) ≈ 32,9 — IMC ≥30 → agenda direto. Clara confirma que o perfil está dentro do critério e avança para agendamento sem fazer pergunta de comorbidade.
✓
M9.2 — IMC 27–29,9: pergunta comorbidade
Quero emagrecer. Peso 80kg e tenho 1,72m
Esperado: IMC = 80 / (1,72²) ≈ 27,0 — IMC na faixa 27–29,9 → Clara PERGUNTA se tem comorbidade (diabetes, hipertensão, colesterol alto etc). Só agenda se tiver comorbidade confirmada.
✓
M9.3 — IMC <27: informa que não há indicação
Quero emagrecer. Peso 62kg e tenho 1,70m
Esperado: IMC = 62 / (1,70²) ≈ 21,5 — IMC <27 → não há indicação médica para medicação emagrecedora. Clara informa o resultado, explica os critérios e pode oferecer consulta de orientação nutricional.
✓
M9.4 — IMC 27–29,9 + comorbidade confirmada: agenda
Peso 82kg, mede 1,72m. Tenho diabetes tipo 2
Esperado: IMC ≈ 27,7 (faixa intermediária) + comorbidade (diabetes) confirmada → agenda direto. Clara reconhece que diabetes qualifica o paciente mesmo com IMC abaixo de 30.
✓
M9.5 — Pede Ozempic diretamente
Quero usar Ozempic para emagrecer
Esperado: Clara não prescreve Ozempic diretamente. Direciona para o fluxo de emagrecimento: coleta peso e altura para calcular IMC, verifica indicação médica antes de avançar para agendamento.
