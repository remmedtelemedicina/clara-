Por que aconteceu
1
O modelo executou 3 etapas em 1 turno
O prompt diz "execute APENAS a etapa correspondente e encerre". Mas o modelo viu "Sim" (confirmação da consulta) e decidiu "ser eficiente" — pulou a leveza, pulou a pergunta do sintoma e foi direto para o checklist de alarme.
Regra violada: "Execute APENAS a etapa correspondente — nunca execute mais de uma etapa por turno"
2
O checklist mostrado não existe no prompt — foi inventado
O modelo não usou nenhum dos 18 grupos de sintoma do prompt. Criou uma lista genérica com sintomas misturados de vários grupos. Isso aconteceu porque ele mostrou o checklist SEM ter recebido o sintoma do paciente — sem saber o grupo, inventou uma lista "universal".
Regra violada: "Copiar texto EXATO dos grupos — não resumir, não adaptar"
Como corrigir
⚠️ São duas correções independentes — uma no prompt (Clara) e uma no N8N (workflow). As duas precisam ser feitas.

Correções necessárias

1
Prompt — Reforçar ETAPA 3 para não pular
Na ETAPA 3 (setor = TRIAGEM_SINTOMA), adicionar instrução explícita para parar após perguntar a leveza e NÃO avançar para checklist sem sintoma.
# ETAPA 3 — Processar confirmação (setor = TRIAGEM_SINTOMA) SIM: Passo 1: atualizar_setor → "TRIAGEM_LEVEZA" Passo 2: output final: "Entendido! ✅ Me confirma que seus sintomas são LEVES? *SIM* ou *NÃO*" 🔴 ENCERRAR IMEDIATAMENTE APÓS ESTE OUTPUT. 🔴 NÃO continuar para próxima etapa. 🔴 NÃO mostrar lista de alarme. 🔴 NÃO pedir sintoma agora — aguardar próximo turno.
2
Prompt — Reforçar ETAPA 3A para não pular
Na ETAPA 3A (setor = TRIAGEM_LEVEZA), adicionar instrução explícita para parar após pedir o sintoma e NÃO mostrar checklist sem ter recebido a resposta.
# ETAPA 3A — Leveza (setor = TRIAGEM_LEVEZA) SIM: Passo 1: atualizar_setor → "TRIAGEM_ALARME" Passo 2: output final: "Me diz rapidinho: qual seu PRINCIPAL SINTOMA agora?" 🔴 ENCERRAR IMEDIATAMENTE APÓS ESTE OUTPUT. 🔴 NÃO identificar grupo de sintoma agora. 🔴 NÃO mostrar checklist agora. 🔴 Aguardar o sintoma no próximo turno.
3
Prompt — ETAPA 3B: só mostrar checklist se sintoma foi informado
No início da ETAPA 3B (MOMENTO 1), adicionar verificação: se não há sintoma na mensagem atual nem na memória, pedir o sintoma antes de qualquer coisa.
# ETAPA 3B — início do MOMENTO 1 🔴 ANTES DE QUALQUER COISA: verificar se paciente informou sintoma. 🔴 Se a mensagem for apenas "Sim", "Ok", "Pode", ou vaga E não há sintoma na memória da conversa → NÃO mostrar checklist. NÃO atualizar setor. Output: "Para eu conseguir te atender, preciso saber: qual é o seu *principal sintoma* agora? (Ex: dor de cabeça, gripe, dor nas costas...)" 🔴 Aguardar resposta. Encerrar turno.
4
N8N — Reset de setor (já documentado)
Parte desses saltos de etapa acontecem porque o setor no banco está em uma etapa avançada de uma conversa anterior. O reset de setor quando paciente inicia nova conversa (já documentado) elimina esse risco.
-- No workflow N8N, antes do agente Clara: SE setor = "ENCERRADO" E tempo > 4h → UPDATE setor = "TRIAGEM_ATIVA" → continuar para Clara com setor resetado
