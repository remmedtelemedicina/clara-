🔁 Cuidado Contínuo — D+120 em diante (Fluxo 1)

A cada 60 dias, enquanto o paciente estiver ativo. Alterna entre 2 mensagens para não repetir.
Mensagem A — Envios 1, 3, 5... (ímpar)
"Oi [NOME]! Passando pra saber como você está. Qualquer coisa — dúvida, renovação ou consulta — estamos aqui!"
Mensagem B — Envios 2, 4, 6... (par)
"Oi [NOME]! Só lembrando que estamos sempre aqui. Tudo pelo celular, sem sair de casa."
⚠️ Só envia se não houve nenhum contato nos últimos 60 dias  •  Ciclo nunca encerra enquanto opt_out = false
Regras Globais
⏸️
Paciente responde → Pausar
Qualquer resposta pausa o ciclo atual. A próxima mensagem não é enviada. O ciclo só retoma no próximo intervalo programado.
🔄
Agenda → Reiniciar Fluxo 1
Se o paciente do Fluxo 2 agendar em qualquer momento, ele migra automaticamente para o Fluxo 1, reiniciando do D+7.
🔴
Opt-out (LGPD — obrigatório)
Palavras: "pare", "stop", "não quero mensagens", "remover", "cancelar". Ação: setar opt_out = true e parar TODOS os envios imediatamente.
Banco de Dados — Campos necessários no Supabase
⚠️ Rodar a migration SQL antes de criar qualquer workflow no N8N. Sem os campos corretos, os triggers não funcionam.

TABELA: clientes

Campo Tipo Descrição
data_ultima_consulta date Base para D+7, D+30, D+60, D+90, D+120. Atualizar após cada consulta confirmada.
data_cadastro date Data do primeiro cadastro. DEFAULT NOW().
opt_out boolean false por padrão. Setar true quando paciente pedir para parar. DEFAULT false.
ultimo_followup date Atualizar após CADA envio (qualquer fluxo). Controla anti-spam e intervalos.
status_paciente text 'ativo' por padrão. Setar 'inativo' após D+90 sem resposta no Fluxo 2. DEFAULT 'ativo'.
respondeu_reativacao boolean Setar true quando paciente responder. Controla se D+90 do Fluxo 2 foi respondido. DEFAULT false.
contagem_bloco_continuo int Contador do cuidado contínuo. Ímpar = Mensagem A, Par = Mensagem B. DEFAULT 0.
fluxo_atual text 'fluxo1' ou 'fluxo2'. Saber em qual fluxo o paciente está. Muda para 'fluxo1' quando agendar.

TABELA: agendamentos

Campo Tipo Descrição
lembrete_enviado boolean Impede que o lembrete de 30min dispare mais de uma vez. DEFAULT false.
etapa_carrinho int 0 = nenhum lembrete enviado, 1 = 30min enviado, 2 = D+1 enviado, 3 = D+30 enviado, 4 = D+90 enviado (encerrado).

// migration.sql — Rodar uma vez no SQL Editor do Supabase

-- Campos na tabela clientes
ALTER TABLE clientes
  ADD COLUMN IF NOT EXISTS data_ultima_consulta     date,
  ADD COLUMN IF NOT EXISTS data_cadastro            date DEFAULT CURRENT_DATE,
  ADD COLUMN IF NOT EXISTS opt_out                  boolean DEFAULT false NOT NULL,
  ADD COLUMN IF NOT EXISTS ultimo_followup          date,
  ADD COLUMN IF NOT EXISTS status_paciente          text    DEFAULT 'ativo' NOT NULL,
  ADD COLUMN IF NOT EXISTS respondeu_reativacao     boolean DEFAULT false NOT NULL,
  ADD COLUMN IF NOT EXISTS contagem_bloco_continuo  int     DEFAULT 0 NOT NULL,
  ADD COLUMN IF NOT EXISTS fluxo_atual              text    DEFAULT 'fluxo2';

-- Campos na tabela agendamentos
ALTER TABLE agendamentos
  ADD COLUMN IF NOT EXISTS lembrete_enviado  boolean DEFAULT false NOT NULL,
  ADD COLUMN IF NOT EXISTS etapa_carrinho    int     DEFAULT 0 NOT NULL;

-- Índices para performance
CREATE INDEX IF NOT EXISTS idx_clientes_ultimo_followup   ON clientes(ultimo_followup);
CREATE INDEX IF NOT EXISTS idx_clientes_data_consulta     ON clientes(data_ultima_consulta);
CREATE INDEX IF NOT EXISTS idx_clientes_opt_out           ON clientes(opt_out);
CREATE INDEX IF NOT EXISTS idx_clientes_status            ON clientes(status_paciente);
