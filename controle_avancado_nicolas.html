Funcionalidade 1 — Kill Switch

Desligar e ligar a Clara instantaneamente via WhatsApp, sem precisar acessar o N8N. Para emergências ou pausas programadas.

Como funciona

1
Dona envia mensagem do seu número pessoal para o número da REMMED
N8N identifica o número como "owner" e entra no modo de comando
2
Comando "pausa" → N8N atualiza Supabase: clara_ativa = false
A partir daí, todas as mensagens de pacientes recebem a mensagem de fora do ar
3
Comando "liga" → N8N atualiza Supabase: clara_ativa = true
Clara volta a atender normalmente

Supabase — tabela config_sistema

Tabela: config_sistema

chaveTEXT (primary key)
valorTEXT
atualizado_emTIMESTAMPTZ DEFAULT NOW()
-- Criar tabela e inserir valores iniciais CREATE TABLE config_sistema ( chave TEXT PRIMARY KEY, valor TEXT, atualizado_em TIMESTAMPTZ DEFAULT NOW() ); INSERT INTO config_sistema VALUES ('clara_ativa', 'true', NOW()), ('owner_telefone', '5511XXXXXXXXX', NOW()), ('msg_fora_do_ar', 'Estamos com atendimento pausado. Retornamos em breve! 🧡', NOW());

Funcionalidade 2 — Lista de Pacientes Bloqueados

Pacientes difíceis ou que não devem ser atendidos pela Clara são ignorados silenciosamente. Dois métodos: etiqueta no WPP ou comando.

Método A — Etiqueta no WhatsApp Business (preferido)

⚠️
Funciona via Evolution API. Quando uma mensagem chega, o payload inclui as etiquetas do contato. Se tiver a etiqueta nao-atender, o N8N ignora e adiciona automaticamente ao Supabase.
1
Criar etiqueta "nao-atender" no WPP Business
WhatsApp Business → Configurações → Etiquetas → Nova etiqueta: "nao-atender"
2
N8N verifica labels no webhook a cada mensagem
IF payload.labels inclui "nao-atender" → não responder + registrar no Supabase
3
Para bloquear: adicionar etiqueta no contato dentro do WPP
Próxima mensagem desse contato é automaticamente ignorada
-- Tabela de bloqueados no Supabase CREATE TABLE pacientes_bloqueados ( telefone TEXT PRIMARY KEY, motivo TEXT, bloqueado_em TIMESTAMPTZ DEFAULT NOW(), origem TEXT -- 'etiqueta_wpp', 'comando', 'manual' ); -- Verificação no N8N (node Function ou IF): -- 1. GET de pacientes_bloqueados WHERE telefone = sender -- 2. SE encontrado → parar, não responder -- 3. SE label "nao-atender" detectada → INSERT + parar

Funcionalidade 3 — Central de Comandos via WhatsApp

A dona controla tudo enviando mensagens do seu número pessoal para o número da REMMED. Simples, rápido, funciona de qualquer lugar.

Todos os comandos disponíveis

Comando O que faz Confirmação enviada de volta
pausa Desliga a Clara — pacientes recebem mensagem de fora do ar "🔴 Clara pausada. Nenhum paciente será atendido."
liga Liga a Clara — atendimento normal retomado "✅ Clara ativa. Atendimento retomado!"
atende 5511999... Reseta setor do paciente para TRIAGEM_ATIVA — Clara retoma o atendimento "▶️ Paciente 5511999... sendo atendido pela Clara."
bloqueia 5511999... Adiciona número à lista de bloqueados "🚫 Número 5511999... bloqueado."
desbloqueia 5511999... Remove número da lista de bloqueados "✅ Número 5511999... desbloqueado."
status Retorna status atual do sistema "📊 Clara: ATIVA | Bloqueados: 3 | Atendimentos hoje: 12"

Como implementar no N8N

1
No início do workflow, verificar se sender = owner_telefone
IF {{ $json.sender }} == {{ $('config').item.json.owner_telefone }} → entrar no modo comando
2
Node "Switch" para identificar qual comando
Cada branch corresponde a um comando: pausa / liga / atende / bloqueia / desbloqueia / status
3
Cada branch executa a ação no Supabase e responde para o owner
Supabase UPDATE + WPP send message de volta para o número do owner com confirmação
4
Parar o workflow — não passar para Clara
Mensagens de comando nunca chegam ao agente Clara
// Node Function — Parser de comandos (JavaScript) const msg = $input.item.json.message.toLowerCase().trim(); const sender = $input.item.json.sender; const owner = $('Config').item.json.owner_telefone; // Verificar se é owner if (sender !== owner) return [{ json: { is_command: false } }]; // Identificar comando if (msg === 'pausa') return [{ json: { cmd: 'pausa' } }]; if (msg === 'liga') return [{ json: { cmd: 'liga' } }]; if (msg === 'status') return [{ json: { cmd: 'status' } }]; if (msg.startsWith('atende ')) { const tel = msg.replace('atende ', '').trim(); return [{ json: { cmd: 'atende', telefone: tel } }]; } if (msg.startsWith('bloqueia ')) { const tel = msg.replace('bloqueia ', '').trim(); return [{ json: { cmd: 'bloqueia', telefone: tel } }]; } if (msg.startsWith('desbloqueia ')) { const tel = msg.replace('desbloqueia ', '').trim(); return [{ json: { cmd: 'desbloqueia', telefone: tel } }]; } // Comando não reconhecido return [{ json: { cmd: 'ajuda' } }];

Funcionalidade 4 — Retomada Após Atendimento Humano

Quando a equipe responde um paciente manualmente, a Clara pausa. Agora ela retoma automaticamente após 30 min de silêncio, ou imediatamente via comando.

Dois caminhos de retomada

▶️ Caminho A — Comando manual
Dona envia do seu número:
atende 5511999...

N8N reseta setor = TRIAGEM_ATIVA.
Próxima mensagem do paciente → Clara atende.
⏱️ Caminho B — Timer automático
Se setor = HUMANO E último contato humano > 30 min atrás → setor = TRIAGEM_ATIVA

Próxima mensagem do paciente é atendida pela Clara automaticamente.
-- Coluna necessária no Supabase (clientes) ALTER TABLE clientes ADD COLUMN IF NOT EXISTS ultimo_contato TIMESTAMPTZ DEFAULT NOW(), ADD COLUMN IF NOT EXISTS ultimo_msg_humano TIMESTAMPTZ; -- Lógica no N8N (antes do agente Clara): -- SE setor = "HUMANO" -- E NOW() - ultimo_msg_humano > 30 minutos -- → UPDATE setor = "TRIAGEM_ATIVA" -- → Clara atende normalmente -- Quando humano responde ao paciente: -- → UPDATE ultimo_msg_humano = NOW() WHERE telefone = paciente

Funcionalidade 5 — Follow-up de Pacientes

Documentado anteriormente (arquivo followup_nicolas.html). Resumo da arquitetura abaixo para referência rápida.

Dois fluxos de follow-up

Fluxo 1 — Pagou e consultou
D+7 → Como foi a consulta?
D+30 → Nova consulta / renovação?
D+60 → Check-up de rotina
D+90 → Manutenção
D+120+ → Paciente ativo permanente
Fluxo 2 — Não agendou (carrinho)
30min → Lembrete urgente
D+1 → Segundo contato
D+30 → Tentativa final
D+90 → Encerrar se sem resposta
